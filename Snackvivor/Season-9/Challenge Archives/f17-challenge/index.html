Let’s review the rules:
8:22 PM
1) When you are ready to start the challenge, run !f17-challenge in your personal submissions channel. 2) You will receive an image after running the command. Identify the movie the image comes from. 3) Use !f17-[movie-title]-[number] as the command to receive the next image. If your movie title has more than one word, be sure to use dashes to separate the words (ex: if you’re trying to guess the title of the 1st image and you think it is Madame Web, you would use !f17-madame-web-1). 4) Continue on until you receive a message that indicates you have completed the challenge. Ping production when you have finished so that we can Snowflake your time.
8:22 PM
IMPORTANT NOTES:
  • Using skips will earn you no points.
  • If a movie is part of a larger series, don’t worry about identifying the exact movie. Ex: If a movie from Star Wars was included (it’s not), you would only have to answer !f17-star-wars-7 NOT !f17-star-wars-empire-strikes-back-7
  • Repeating this: you CANNOT use reverse image searching. Seriously, don’t do it.
